# Qwenbsprompt: Интеграция с RAS для анализа проектов

## Установка
1. Скачайте `ras.py` из репозитория:  
   ```bash
   curl -O https://raw.githubusercontent.com/KilixKilik/RAS/main/ras.py
   ```
   или вручную через [ссылку](https://github.com/KilixKilik/RAS/raw/main/ras.py)

2. Поместите файл в корневую папку вашего проекта

## Как использовать с Qwen
1. Запустите скрипт:  
   ```bash
   python ras.py
   ```
   - В папке `ras/` появятся отчёты по структуре проекта

2. В Qwen:
   - Выберите модель **Qwen3-VL-235B-A22B**
   - Включите режим **"Мышление"**
   - Отправьте промпт:

```
Короче я тебе буду кидать файлы для работы ты их должен ГРАМОТНО изучить

Структура:
Папка
----Файл
содержимое
```

## Важно
- Для корректной работы требуется **Python 3.6+**
- Не забудьте включить **режим мышления** в Qwen
